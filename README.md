# Employee Management System — Manual Testing Portfolio

A fictional HR application test-design practice project for entry-level QA. No live application was tested. All 50 cases are Not Run; defect reports are hypothetical examples.

## Coverage
Login, employee registration, directory search, profile management and leave management (10 cases each).

Skills: functional, positive/negative, boundary, smoke, sanity and regression testing; defect reporting and STLC. CSV files can be viewed in GitHub or Excel. No installation is needed to review this portfolio.
